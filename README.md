# 🚗 Vehicle Management System

A console-based **Vehicle Management System** developed in **C** for the Programming Fundamentals project at **National University of Computer & Emerging Sciences (FAST-NUCES)**.

The system is designed to manage vehicle records, owner information, vehicle status, and maintenance details in an organized and efficient way.

## 📌 Project Overview

The Vehicle Management System allows users to manage vehicle-related information through a simple console-based interface.

It provides functionality for:

- Adding vehicles
- Updating vehicle information
- Searching for vehicles
- Deleting vehicle records
- Storing owner information
- Tracking vehicle status
- Recording maintenance history
- Tracking maintenance costs
- Displaying available vehicles
- Permanently storing records using files

## ❗ Problem Statement

Maintaining vehicle records manually can lead to:

- Data loss
- Duplicate records
- Difficulty tracking vehicle status
- Difficulty maintaining maintenance history
- Increased time and effort

This project provides a computerized solution to organize and manage these records efficiently.

## 💡 Proposed Solution

The system digitally manages vehicle records and provides different operations for adding, searching, updating, and deleting vehicles.

It also allows users to track vehicle maintenance, maintenance costs, and vehicle availability.

## ✨ Features

### Vehicle Management
- Add a new vehicle
- Update vehicle information
- Search for a vehicle
- Delete a vehicle
- Display available vehicles

### Owner Management
- Store owner information
- Associate owners with vehicles

### Vehicle Status
- Track the current status of vehicles
- Check vehicle availability

### Maintenance Management
- Record maintenance history
- Track maintenance costs

### File Handling
- Store records permanently using files
- Load previously saved records when the program starts
